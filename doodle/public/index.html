    THE SHORT VERSION

    Draw. Guess. Repeat.

    1. Create a room and share the invite link or code with 2–8 players.
    2. Everyone gets one turn to draw a secret word. Each turn starts with 60 seconds.
    3. The host can add 15 seconds at a time while the timer is running.
    4. Each player who guesses correctly earns 10 points. The drawer earns 10 points once if anyone gets it.
    5. No correct guesses? No points. When everyone has drawn, the highest score wins. Ties are shared!

    Keep your word a secret. Please don't draw letters or spell it out!
